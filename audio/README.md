# Audio

La v1 utilise par défaut `SpeechSynthesis` et les voix locales de l'appareil pour les scripts originaux lorsqu'aucun MP3 n'est encore fourni.

Le modèle de question accepte également `audioUrl` et `audio.mode = remote` pour les packs ETS autorisés en hotlink.

Les futurs MP3 originaux seront stockés sous `public/audio/`.
