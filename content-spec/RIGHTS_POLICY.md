# Politique de provenance et droits

From0to990 doit pouvoir auditer l'origine de chaque texte, image, audio et ambiance.

Pour toute ressource tierce conserver :
- URL source ;
- fournisseur/auteur ;
- type de licence ou référence d'autorisation ;
- date de validation ;
- obligations d'attribution ;
- droit de redistribution ou hotlink uniquement ;
- politique de cache ;
- checksum uniquement lorsqu'un fichier peut légalement être stocké.

Les autorisations particulières contenant des données personnelles ne sont pas publiées dans le dépôt public. Le dépôt ne conserve qu'une référence interne et les règles d'usage autorisées.

Une ressource `authorized-hotlink` ne doit jamais être transformée automatiquement en fichier local permanent.
