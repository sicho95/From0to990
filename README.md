# From 0 to 990

PWA local-first de préparation adaptative au TOEIC® Listening & Reading.

Le dépôt GitHub est la source maître du code, du contenu pédagogique et du déploiement GitHub Pages.

- responsive laptop / grand écran / iPad / iPhone ;
- IndexedDB locale + fonctionnement offline ;
- mises à jour PWA automatiques ;
- moteur adaptatif selon résultats, vitesse et erreurs ;
- TOEIC blanc original 200 questions (100 Listening + 100 Reading) ;
- backend optionnel via API, première cible @Sites + D1 ;
- export/import administrateur pour migration future.

> TOEIC® est une marque d’ETS. Ce projet n’est ni affilié ni approuvé par ETS. Les exercices sont originaux et de type TOEIC.
